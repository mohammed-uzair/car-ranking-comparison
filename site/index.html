Body type checkboxes are sent directly in the Autohero search request itself (a real filter field — confirmed by capturing Autohero's own site's network traffic, see site.md), not fetched-then-filtered: unchecking all leaves it unrestricted (Autohero-only; AutoScout24 is unaffected, use "Only show" for text-matching there).
